# Лабораторные работы 11–12 на C#

Нужны SDK .NET 8, Visual Studio 2022 (для запуска из IDE) и Docker Desktop для SQL Server в ЛР11. Для ЛР12 и TCP Docker не нужен. При первой сборке потребуется доступ к NuGet. API-ключи не нужны.

Решение — `Labs11_12.sln`. Команды ниже выполняй в PowerShell из папки с этим файлом. Сервер и клиент запускай в разных вкладках терминала.

## ЛР11, часть 1: последняя цена по TCP

1. В готовой ЛР10 загрузи данные. Можно запустить её с `--demo`, выбрать «да» и получить `stocks_demo.db`. Для настоящих котировок из публичного примера ЛР10 используй `--sample` и `stocks_sample.db`.
2. Найди файл базы ЛР10 и передай серверу его полный путь. Это база SQLite из прежнего проекта.
3. Запусти клиента и введи тикер.

```powershell
dotnet run --project Lab11TcpServer -- "C:\путь\к\stocks_demo.db"
```

В другой вкладке:

```powershell
dotnet run --project Lab11TcpClient
```

Введи `TEST_UP`: на учебной базе ЛР10 последняя цена — 12 за 2026-01-02. Если открываешь `stocks_sample.db`, введи `AAPL`. Для неизвестного тикера должно быть «Тикер или цена не найдены». Дата — дата последней записи, а не обязательно сегодня.

Если базы ЛР10 под рукой нет, команда `dotnet run --project Lab11TcpServer -- --demo` создаст **отдельную** учебную базу для демонстрации протокола. Обычный режим открывает БД ЛР10 только для чтения.

## ЛР11, часть 2: Northwind REST API

Включи Docker Desktop. Задай придуманный тобой пароль SQL Server и запусти подготовку базы:

```powershell
$env:MSSQL_SA_PASSWORD = Read-Host "Пароль SQL Server"
powershell -ExecutionPolicy Bypass -File .\Init-Northwind.ps1
dotnet run --project Lab11NorthwindApi
```

Пароль должен удовлетворять политике SQL Server (не короче 8 символов, не менее трёх разных категорий: прописные, строчные, цифры, специальные). Скрипт создаёт контейнер, ждёт готовности SQL Server и устанавливает оригинальную Northwind скриптом Microsoft. Существующая Northwind с таблицей Categories не перезаписывается. Используй тот же пароль при повторном запуске существующего контейнера, если пароль в БД не менялся.

Во второй вкладке:

```powershell
dotnet run --project Lab11NorthwindClient
```

Проверь пункты: **1** — список; **3** — создай категорию с коротким названием, запомни её ID из ответа; **2** — прочитай её; **4** — измени; **5** — удали; **2** — снова запроси её ID и получи HTTP 404. Создание возвращает 201, изменение и удаление — 204. Для проверки удаления используй свою новую категорию: некоторые исходные категории связаны с товарами и возвращают 409.

Если Docker сейчас недоступен, API можно запустить с `dotnet run --project Lab11NorthwindApi -- --Demo=true` и этим же клиентом проверить CRUD на отдельной учебной SQLite. Для сдачи основной части с Northwind запускай SQL Server по инструкции выше.

Останови приложения через Ctrl+C. Контейнер останавливается командой `docker compose stop`; данные в томе сохраняются.

## ЛР12: приёмное отделение больницы

Порядковый номер 23 → `23 % 20 = 3` → вариант «Приёмное отделение больницы». Три таблицы: пациенты, врачи, обращения. Обращение связано с одним пациентом и одним врачом. База `hospital.db` создаётся автоматически.

```powershell
dotnet run --project Lab12
```

Открой в браузере **http://127.0.0.1:5113**.

1. В «Пациентах» добавь вымышленного пациента, например Иван Тестов, 1999.
2. Во «Врачах» добавь Анну Тестову, специальность «Терапевт».
3. В «Обращениях» выбери этого пациента и врача, заполни дату и жалобу.
4. На каждой странице нажми «Изменить», поменяй значения, сохрани и проверь список.
5. Попробуй удалить пациента при существующем обращении: страница покажет причину отказа.
6. Удали обращение, затем пациента и врача. Убедись, что записи исчезли.
7. Чтобы проверить сохранение между запусками, создай запись, перезапусти приложение и проверь список.

В Visual Studio вместо команд можно назначать нужный проект запускаемым и передавать аргументы через свойства запуска. Для двух процессов одновременно удобнее терминал.
