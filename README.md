# Лабораторные работы 7–10 на C#

Открой Labs07_10.sln в Visual Studio 2022 с поддержкой .NET 8. Для окна погоды нужна рабочая нагрузка «Разработка классических приложений .NET». При первой сборке восстановятся NuGet-пакеты. В ЛР10 используется EF Core 8.0.15 и SQLite: это разрешено заданием, SQL Server устанавливать не нужно.

Каждый проект запускается отдельно. В Visual Studio выбери его запускаемым проектом и нажми Ctrl+F5. В терминале запускай команды из папки Labs07_10. Простые циклы и методы оставлены намеренно, чтобы код было удобно разбирать на защите.

## ЛР7

AnimalLibrary — отдельная библиотека с Animal, Cow, Lion, Pig, двумя перечислениями и CommentAttribute. Lab07 — приложение для генерации XML рефлексией.

```
dotnet run --project Lab07 -- diagram.xml
```

В diagram.xml сохраняются типы, базовые классы, свойства, поля, конструкторы, методы с параметрами и атрибуты, в том числе Comment.

## ЛР8

Animal в диаграмме абстрактный: создать new Animal нельзя. Поэтому переменная типа Animal содержит Cow. XmlInclude сохраняет конкретный тип; при чтении он восстанавливается. Для обоих приложений укажи один и тот же путь:

```
dotnet run --project Lab08Serialize -- animal.xml
dotnet run --project Lab08Deserialize -- animal.xml
dotnet run --project Lab08Files
```

В третьей программе введи исходную папку, точное имя файла с расширением и «да» для сжатия. Поиск проверяет исходную папку и вложенные, пропускает ссылки на каталоги, чтобы не зациклиться. Содержимое читается как текст через FileStream и StreamReader. Архив имеет формат GZip (.gz), исходный файл сохраняется; готовый архив не перезаписывается.

## ЛР9 — акции

Исходный ticker.txt сохранён целиком в Data. Для реального сбора зарегистрируйся на https://www.marketdata.app/ и получи токен в кабинете. Он отличается от ключа OpenWeather. В PowerShell текущего окна:

```powershell
$env:MARKETDATA_TOKEN="твой_токен"
dotnet run --project Lab09Stocks
```

Для всех уникальных непустых тикеров запрашивается период от текущей даты минус год до текущей даты. Для каждого дня считается (High+Low)/2, затем среднее по доступным торговым дням. После ответа запускается Task.Run для расчёта и записи. Запись в общий файл защищена lock. Программа ждёт Task.WhenAll. averages.txt содержит Тикер:Цена. Ошибки отдельных тикеров идут в errors.txt. При HTTP 401/403/429 дальнейший сбор прекращается; уже запущенные расчёты завершаются. Пауза 1,1 секунды уменьшает частоту запросов, но не заменяет проверку квоты тарифа. Если квота закончилась, полный файл не получится. Старые тикеры из исходного файла могут быть недоступны у поставщика.

Без токена также доступен публичный пример API AAPL:

```
dotnet run --project Lab09Stocks -- --sample
dotnet run --project Lab10 -- --sample
```

В первом случае результат попадёт в averages_sample.txt, во втором — в отдельную stocks_sample.db. Это настоящая сетевая загрузка одного тикера; доступность публичного примера зависит от Market Data. Для Lab10 введи «да», затем AAPL. Полный список этим режимом не заменяется.

Без токена можно проверить вычисления на трёх явно вымышленных бумагах:

```
dotnet run --project Lab09Stocks -- --demo
```

Демонстрация использует две даты для проверки формулы и конкурентной записи; она не заменяет сбор годовой истории. Файлы averages_demo.txt и errors_demo.txt отделены от реальных результатов.

## ЛР9 — погода

Для Windows запускай Lab09Weather. В окне выбери город, введи свой ключ OpenWeather и нажми «Загрузить погоду». Поле ключа скрывает символы; ключ не сохраняется. Галочка «Учебный ответ JSON» проверяет отображение на фиксированном ответе без сети. При await сетевой запрос не блокирует окно; кнопка недоступна до завершения запроса. Список городов загружается из оригинального city.txt.

Для Linux/macOS есть разрешённый заданием консольный вариант:

```
dotnet run --project Lab09WeatherConsole -- --demo
```

Для настоящей погоды задай OPENWEATHER_API_KEY и запусти без --demo. Пример PowerShell:

```powershell
$env:OPENWEATHER_API_KEY="твой_ключ"
dotnet run --project Lab09WeatherConsole
```

## ЛР10

```
dotnet run --project Lab10
```

Введи «да» для загрузки цен из API (нужен MARKETDATA_TOKEN). База stocks.db создаётся автоматически через EF Core. Затем вводи тикеры; пустая строка завершает программу. Можно ответить «нет» и посмотреть ранее сохранённые данные без API.

Схема: Stocks — тикеры; StockPrices — дневные High, Low и Close с датой; TodaysConditions — результат сравнения двух последних доступных торговых дней. Для сравнения используется Close. Уникальные индексы предотвращают дубли тикеров, дат и итоговых состояний. При повторной загрузке цены обновляются. Если доступно меньше двух дней, сравнение не выводится. На выходных и при задержке данных выводится дата последней свечи и предупреждение, что это не цена за сегодняшний день.

```
dotnet run --project Lab10 -- --demo
```

Учебные данные попадут в отдельную stocks_demo.db. Введи «да», затем TEST_UP, TEST_DOWN и TEST_SAME: получишь рост, падение и отсутствие изменения соответственно. Это проверка базы и логики; данные не являются реальными котировками.

## Что проверено

Все исходники скомпилированы .NET 8, включая WinForms с WindowsDesktop reference pack. На Linux выполнены консольные части; запуск самого окна Windows не выполнялся. Проверены XML, восстановление Cow, поиск и побайтное восстановление GZip, средние и запись нескольких задач, разбор всех городов, EF Core SQLite, три состояния и повторный импорт без дублей. Фактические выводы и созданные XML находятся в Results. Для реального годового сбора нужен пользовательский токен Market Data. Публичный пример AAPL дополнительно проверен живым запросом: получены 250 дневных свечей; они сохранены через EF Core в отдельную базу. Ключи в комплект не включены.

Отчёты PDF и редактируемые DOCX предоставлены отдельно в комплекте лабораторных работ. В отчётах указано, где использовались учебные данные.
